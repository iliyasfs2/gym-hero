# 🏋️ Gym Hero

**Modern Fitness Management Platform built with Next.js and Supabase**

Gym Hero is a modern fitness management platform designed to help gyms manage members, track fitness information, visualize progress, and provide a smooth digital experience for both administrators and members.

The platform combines a responsive modern UI with powerful management features, analytics dashboards, BMI tracking, and payment simulation capabilities.

---

## ✨ Features

### 🔐 Authentication

* Secure user authentication
* Login system with role-based access
* Separate experiences for admins and members

### 📊 Admin Dashboard

* Complete gym management dashboard
* Member overview and statistics
* Data visualization with interactive charts
* Management tools for gym operations

### 👤 Member Dashboard

* Personalized member area
* Fitness progress overview
* Account and profile management
* Access to personal fitness information

### 🧮 BMI Calculator

* Calculate Body Mass Index
* Display fitness status
* Track health-related information

### 💳 Payment System

* Test payment gateway integration
* Simulated payment flow
* Payment status management

### 📱 Responsive Design

* Fully responsive interface
* Optimized for desktop, tablet, and mobile devices
* Modern UI built with a clean user experience

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/iliyasfs2/gym-hero.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

## 🔑 Environment Variables

Create a `.env.local` file and add your environment variables:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```
